INT253 Course Project

CivicConnect Architecture & Outcomes

A full-stack Django platform mapping modern software engineering principles with INT253 Course Outcomes.

Project Mission

CivicConnect is a societal challenge crowdsourcing and co-solution platform that bridges the gap between citizens reporting real-world challenges, students innovating sustainable answers, academic institutions offering research mentorship, and industry leaders sponsoring pilot implementations.

Demonstration of INT253 Course Outcomes

CO1
Installation & App Structuring

Project creation, settings configuration, and modular multi-app architecture.

  • Configured Django with clean settings separation.
  • Divided monolithic concerns into 6 modular apps: accounts, challenges, solutions, collaborations, partnerships, and dashboard.
  • Configured static files, media uploads, and custom context processors.
CO2
Views, URLs & HTTP Methods

URL routing, RESTful design patterns, and HTTP request/response lifecycles.

  • App-level URL namespacing (challenges:list, dashboard:index).
  • Multi-criteria GET queries: searching by title/keyword, filtering by category, severity, status, and sorting.
  • Built-in pagination with Paginator handling dynamic page numbers and empty edge cases.
CO3
Django Templates & UI

Template inheritance, dynamic tags, context processors, and responsive UI.

  • Master template base.html with modular blocks and modern navbar.
  • Custom context processor user_roles_processor exposing role flags across all templates.
  • Modern Bootstrap 5 UI, responsive cards, and clean typography.
CO4
Django Forms & Validation

ModelForms, field widgets, CSRF tokens, and custom clean() validation.

  • Custom UserRegistrationForm with password confirmation and role-specific validation.
  • ChallengeForm, SolutionForm, ProjectForm, and PartnershipRequestForm.
  • Enforced CSRF protection on all POST requests and server-side validation error displays.
CO5
Models, ORM & Django Admin

Relational database schemas, migrations, aggregations, and admin customization.

  • 10 relational models: CustomUser, Category, Challenge, Vote, Comment, Solution, Project, ProjectMembership, PartnershipRequest, Activity.
  • Relational constraints: ForeignKey, UniqueConstraint (one vote per user, unique project memberships).
  • Customized Django Admin with 1-click batch actions (e.g., Approve Challenges, Reject Challenges).
CO6
Sessions, Cookies & Auth

Authentication framework, session security, and role-based access control.

  • Django authentication with secure password hashing (PBKDF2).
  • 4 distinct roles: Citizen/Student, University, Industry, and Platform Administrator.
  • Role-specific dashboards dynamically query DB stats based on user session.
  • Django Messages Framework communicating flash notifications.
